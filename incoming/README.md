# Adding new photos & videos

1. On GitHub, open the folder for the right category below.
2. Click **Add file → Upload files**, drag in the photos/videos straight from your phone (HEIC, JPG, PNG, MOV, MP4 all fine), and click **Commit changes**.
3. Within a few minutes a robot converts them, removes location data, adds them to the gallery and the site updates.

| Folder | What goes in it |
|---|---|
| `incoming/kids/` | Children's face painting |
| `incoming/adults/` | Adult face painting & body art |
| `incoming/glitter-bar/` | Glitter bar looks |
| `incoming/glitter-tattoos/` | Glitter tattoos |
| `incoming/corporate/` | Event set-ups, Simona at work, corporate events |
| `incoming/seasonal/` | Halloween, Christmas, Pride, Day of the Dead |
| `incoming/videos/` | Short video clips (best under 15 seconds) |

Optional: to improve Google results, edit `src/data/gallery.json` afterwards and replace the default description (`alt`) with what the design is, e.g. "Purple unicorn face paint with glitter". Never include a child's name.
